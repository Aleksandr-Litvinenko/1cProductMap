# Карта продуктов 1С

Интерактивный навигатор по линейке 1С для сайта [kodar-msk.ru](https://kodar-msk.ru).
Проект ведёт **ООО «Кодар»**, официальный партнёр 1С и Битрикс24.

Задача: человек, который про 1С почти ничего не знает, должен за несколько минут
понять, **какие вообще бывают продукты, чем они отличаются и что нужно именно ему** —
не читая прайс-лист и не зная названий заранее.

> **В этом репозитории — только описание проекта.**
> Исходник самого сервиса передаётся разработчику отдельно, см. [«Где лежит продукт»](#где-лежит-продукт).

---

## Как это устроено

Навигатор построен на двух осях: **задача → этажи → карточка**.

### Экран 1. Задачи

Вход не с названий программ, а с человеческой формулировки задачи:
«Считать деньги и сдавать отчётность», «Продавать и вести склад», «Производить
продукцию» и так далее — всего 7 задач плюс 2 комплексные («Нужно всё сразу —
мы небольшие» и «— мы крупные»).

Этот шаг можно пропустить кнопкой **«Хочу увидеть всё сам»** — тогда открывается
полный каталог без фильтра по задаче.

### Экран 2. Этажи

Внутри выбранной задачи — пять этажей, между которыми листают колесом мыши.
Прокрутка замкнута в кольцо: за последним этажом идёт первый.

| Этаж | Что там | Сколько выбирается |
|---|---|---|
| Конфигурации | основные программы учёта | одна |
| Государственные конфигурации | для бюджетной сферы | одна |
| Сервисы 1С | подключаются к конфигурации | сколько нужно |
| Вспомогательные сервисы | технологические, для ИТ-службы | сколько нужно |
| Размещение | где программа физически работает | одно |

Пустые для текущей задачи этажи в кольцо не попадают: если у задачи нет
государственных конфигураций, этажа просто нет.

### Экран 3. Карточка

Полное описание продукта: «простыми словами», подробное описание, «берите если» /
«не берите если», редакции (ПРОФ, КОРП и прочие), характеристики, переход на форму
заявки.

## Механики

**Размер компании.** Ползунок «сколько человек в компании» (1 → 1000+) приглушает
карточки, которые не попадают в указанный диапазон. Логика линейки становится видна
одним движением: на 10 сотрудниках гаснет половина каталога.

**Сборка комплекта.** Кнопка `+` на карточке кладёт продукт в один из трёх слотов —
конфигурация, сервисы, размещение. Когда конфигурация и размещение выбраны, появляется
кнопка расчёта. Это чинит главное непонимание новичков: программа, сервисы и
размещение — три отдельных решения, а не одно.

**Счётчик изученного** — сколько карточек человек открыл из общего числа.

**Редакции внутри карточки.** ПРОФ и КОРП не разведены по отдельным карточкам —
это путало. Вместо этого одна карточка продукта, а внутри разбор: какая редакция
кому и когда переплата.

**Партнёрские решения помечены.** Продукты, которые разрабатывает не фирма «1С»,
несут метку «решение партнёра» с указанием разработчика.

## Где лежит продукт

Исходник сервиса (один самодостаточный HTML-файл) в этот репозиторий **не входит** —
он передаётся разработчику отдельной папкой вместе с инструкцией по встраиванию
в сайт (`INTEGRATION.md`). Там же описано, куда подключается CRM-форма Битрикс24.

## Правила проекта

1. **Все описания написаны своими словами.** Копировать тексты с 1c.ru, v8.1c.ru
   и its.1c.ru нельзя: это чужое авторское право и одновременно дубли для поиска.
2. **Названия продуктов — канонические.** Короткое имя на карточке, полное
   официальное — на странице продукта.
3. **Цены не публикуем.** 1С регулярно пересматривает прайс, устаревшая цена
   бьёт по доверию сильнее, чем её отсутствие помогает.
4. **Разработчик указывается честно.** Если продукт делает партнёр, а не фирма
   «1С», это написано на карточке.
5. **Факты проверяются по первоисточникам** — официальным страницам продуктов,
   а не по памяти.
