# Дизайн-система: Kinetics

Версия 3. Построена на [Kinetics](https://kinetics.colorion.co/) — библиотеке
интерфейсной анимации на пружинной физике вместо кривых с фиксированной
длительностью.

## Что взято

**Движение.** Два токена и больше ничего:

```css
--spring: cubic-bezier(0.34, 1.56, 0.64, 1);   /* с перелётом */
--glide:  cubic-bezier(0.16, 1, 0.3, 1);       /* торможение без перелёта */
```

Правило простое: **то, что человек толкнул сам, отвечает пружиной; то, что
приехало само, тормозит без перелёта.** Третьей кривой в интерфейсе быть не
должно — иначе движение перестаёт что-либо значить.

**Палитра.** graphite для поверхностей, bone для текста, amber для сигнала.

| Роль | Тёмная | Светлая |
|---|---|---|
| Фон | `#0e0e10` | `#f4f2ee` |
| Поверхность | `#1a1a1d` | `#ffffff` |
| Линия | `#2a2a2e` | `#ddd9d2` |
| Текст | `#ede9e0` | `#0e0e10` |
| Текст приглушённый | `#a8a6a0` | `#3f3d39` |
| Текст третьего плана | `#918e85` | `#5c5952` |
| Акцент | `#ff8a00` | `#9c5600` |

**Метрика.** Радиусы 14 и 9 пикселей, пилюля 100.

## Что не взято и почему

**Контурные цвета продуктов остались прежними.** Палитра библиотеки даёт четыре
сигнальных цвета, а этажам и задачам нужно восемь различимых. Прежний набор
выверен симуляцией дальтонизма (матрицы Machado) и CIEDE2000 — менять его на
менее проверенный нельзя.

**`--text-subtle` поднят** с библиотечного `#6e6c68` до `#918e85`: оригинал даёт
3.68:1 на фоне, а это ниже порога для текста. В библиотеке он используется для
декоративных подписей, у нас — для настоящих.

**Светлая тема выведена самостоятельно.** Kinetics существует только в тёмном.
Роли те же, поверхности перевёрнуты, янтарь затемнён: `#ff8a00` на светлом фоне
даёт 2.1:1 и нечитаем.

## Какие эффекты где

| Эффект | Где применён | Зачем |
|---|---|---|
| Squish button | все кнопки | нажатие сжимает быстро, отпускание пружинит |
| Magnetic button | «Получить расчёт», «Раскрыть подробно», «Отправить» | по главной кнопке труднее промахнуться |
| Ripple feedback | кнопки и «плюс» | отклик до того, как интерфейс перерисовался |
| Like burst | «плюс» на карточке | подтверждение попадания в комплект без слов |
| Stagger entrance | карточки этажа | видно, что их несколько, до того как прочтёшь |
| Tab pill glide | редакция, лицензии, режим | один переключатель, а не два индикатора |
| Accordion spring | панель расчёта | понятно, куда делось содержимое |
| Odometer count-up | суммы комплекта | видно «стало дороже», а не просто новое число |
| Success check draw | экран после отправки | полсекунды, за которые ясно: ушло |
| Progress ring | счётчик изученного | доля читается раньше цифр |
| Status pill | «комплект собран» | меняется фон, а не только текст |
| Underline draw | крошки | подчёркивание выезжает из центра |
| Choice chips | позиции в корзине | появление пружиной |
| Rubber-band slider | ползунок размера компании | ручка растёт под пальцем |
| Toast overshoot | добавление в комплект | подтверждение, когда панель свёрнута |

## Ограничения движения

Всё уважает `prefers-reduced-motion: reduce` — при выключенной анимации эффекты
**не запускаются вовсе**, а не проигрываются быстрее. Магнит, рябь, волна и
одометр в этом режиме просто не срабатывают, значения подставляются сразу.

## Проверка контраста

Меряется пиксельно: цвет закрашивается в канву и читается обратно. Иначе никак —
в вычисленных стилях лежат `oklch()` и `color-mix()`, которые обычный разбор
строки превращает в мусор. На время замера переходы отключаются, иначе цвет
ловится на полпути.

Последний прогон: **0 провалов из 50 видимых текстовых узлов** в каждой теме.

## Лицензия библиотеки

У репозитория Kinetics нет файла лицензии. Сайт подаёт эффекты как рецепты для
копирования и раздаёт их тремя способами (CSS, React, промпт для ИИ), то есть
намерение автора очевидно, но формального разрешения нет. В карте эффекты
написаны заново по описанию, файлы библиотеки не копировались. Если проект будет
распространяться дальше, стоит написать автору и уточнить условия.
